Table Turn Evidence
Formulas, filters, exclusions, mode definitions (KDS vs Proxy), and LLM restrictions. This page defines how table-turn opportunities are detected and what blocks verification.
Formula trace
Theoretical turns = svc hrs × 60 ÷ target Actual turns = svc hrs × 60 ÷ actual Turn deficit = theoretical − actual Lost covers = floor(deficit × seats × haircut) Revenue / svc = lost covers × avg check Monthly = weekly × 4.33

Lost covers always floored, never rounded up. Realization haircut applied before flooring.

Filters & exclusions
DINE_IN only. TAKE_OUT and DELIVERY do not have meaningful dining duration and are excluded entirely.
Voided checks excluded. Voids don't represent real cover throughput.
Still-open checks excluded from closed-period analysis. Open-check duration is meaningless until the check closes.
Comped services excluded from avg-check baseline. Comps distort revenue/cover.

All exclusions are enforced before duration math runs. Filter state is visible in the legacy Stage Flow filter bar.

KDS vs Proxy mode
KDS MODE · default. Kitchen Display System provides stage timing (Seat→Order, Order→Food, Food→Dessert, Dessert→Check). Stage decomposition active.
PROXY MODE · KDS data missing. Total duration only (seat → close), no stage decomposition. Outputs labeled [PROXY] / [HEURISTIC].

Proxy mode is a data quality state, not a separate destination. Mode auto-switches based on KDS feed availability.

Guardrails (verification-side)
Avg check must not drop during monitoring window. Per-cover spend tracked per service.
Guest sentiment must not worsen. Tracked via review platforms + complaint patterns.
Complaints / 100 covers must not rise. Front-line rushing signal.
Manager override allowed at any point. Pauses monitoring window.

Faster turns are not counted as verified recovery if check or sentiment degrades — even if covers/service improved.

Confidence rules
Floor for detection60%

Confidence reflects KDS feed health, sample size, and pattern strength. Proxy mode is workable but capped.

LLM restrictions

Claude (Sonnet) generates stage-level analysis and natural-language summaries, but is not permitted to:

— Override realization haircut or seat capacity.
— Round lost covers up. Floor rule is hard.
— Call estimated revenue "saved" or "recovered" in any output.
— Suppress Proxy/Heuristic labels when KDS data is unavailable.

LLM outputs are decision-support only. Final authority is the operator.
